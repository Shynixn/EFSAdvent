GameCube ISO Import

Streams disc assets directly into browser OPFS storage — no full-file buffering.

This app only extracts images and resources from a game file you provide. It does not ship or include any game content of its own — you must supply your own copy.

No files are uploaded anywhere. Everything is processed and kept locally in your web browser.
